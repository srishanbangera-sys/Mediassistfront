# MediAssist

**MediAssist** is an AI-powered healthcare assistance project designed to predict possible diseases based on user-provided symptoms. It demonstrates the use of **Machine Learning and AI** to support preliminary health-related predictions.

## Features

* Symptom-based disease prediction
* Machine Learning-based prediction model
* Simple and user-friendly interface
* Provides predicted disease based on selected symptoms
* Designed as an educational AI/ML project

## Tech Stack

| Technology       | Purpose                       |
| ---------------- | ----------------------------- |
| Python           | Core development              |
| Machine Learning | Disease prediction            |
| Pandas           | Data processing               |
| Scikit-learn     | Model training and prediction |
| HTML/CSS         | User interface                |

## How It Works

```text
User selects symptoms
        ↓
Data preprocessing
        ↓
ML prediction model
        ↓
Predicted disease
        ↓
Result displayed to user
```

## Disclaimer

MediAssist is an **educational project** and is not intended to provide medical diagnosis or replace professional medical advice.
